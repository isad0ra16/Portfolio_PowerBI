## Projetos

### 📢 [Análise de Campanhas de Marketing](.Dashboards/Analise%20de%20Campanhas%20de%20marketing/Analise%20de%20Campanhas%20de%20marketing.md)

Desenvolvido no curso de Power BI da Data Science Academy (em andamento). Quatro visões: perfil dos clientes, comportamento de compra, performance das campanhas e padrões de compra por país.

**Perguntas que o dashboard responde:**

- Qual é o perfil dos clientes e por quais canais eles compram (loja, web, catálogo)?
- Como renda e composição familiar se relacionam com os gastos?
- Quais campanhas tiveram mais efetividade e quais perfis converteram mais?
- Como o consumo varia entre países e ao longo dos anos?

**O que apliquei:** limpeza e remoção de duplicidades no Power Query, modelagem dimensional com relacionamentos e cardinalidade definidos, medidas em DAX e interface desenhada no Figma.

### 🛒 [Dashboard de Análise de Vendas](.Dashboards/Dashboard%20de%20Vendas/Dashboard%20de%20Vendas.md)

Dashboard de vendas em que apliquei conceitos de UX/UI do curso de Sayuri Valente (Xperiun), com identidade visual própria criada no Figma.

**Perguntas que o dashboard responde:**

- Qual é o valor total de vendas?
- Quantas vendas houve por categoria de produto?
- Como as vendas se distribuem por país, considerando a prioridade de entrega?
- Qual é a média de desconto por subcategoria?
- Quais países têm a maior média de valor de venda?

**O que apliquei:** tratamento dos dados no Power Query, medidas em DAX, hierarquia visual, escolha de cores e tipografia e organização dos elementos para leitura rápida dos indicadores.

## Ferramentas

| Ferramenta | Uso nos projetos |
| --- | --- |
| Power BI | Dashboards e visualizações interativas |
| Power Query | Tratamento, limpeza e transformação dos dados (ETL) |
| DAX | Medidas e indicadores |
| Modelagem de dados | Relacionamentos entre tabelas e modelo dimensional |
| Figma | Identidade visual e design da interface dos dashboards |

## Como abrir

Baixe o arquivo `.pbix` da pasta do projeto e abra no Power BI Desktop.
